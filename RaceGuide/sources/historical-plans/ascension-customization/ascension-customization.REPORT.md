## Installation and preservation

- Added 11,135 `CharSections` records, retaining all 536,060 original records and the original string pool.
- Added 405 `BarberShopStyle` records, retaining all 7,473 original records. Some skin selections already
  had matching barber records. Final table counts are 547,195 and 7,878.
- Installed 14,507 additional texture paths under `Character\EsteriaAscensionCustomization\`.
  Existing textures were reused when their bytes matched. Conflicting assets received separate paths.
- The two merged DBCs are identical in root and enUS Z archives and the server's actual bind mounts.
- Preserved all 27,324 unrelated root archive entries and all 10,357 unrelated locale entries byte-for-byte.
  Archive bookkeeping is regenerated by StormLib.
- Race IDs, display IDs, models, hairstyle geometry, custom races, GlueXML, and native extensions are unchanged.
- Existing Human bald choices have the newly added color combinations. Draenei male donor hair selections
  8/9 were mapped to the existing equivalent geometries, preserving the installed ordering.
- No world, character, or Playerbot appearance records were rewritten. No SQL, C++, or builds were required.
- Restarted only `ac-worldserver`; the fresh startup reached `(worldserver-daemon) ready` with no errors
  naming either changed appearance DBC. The container sees the installed table hashes.

## Donor defects and boundaries

The author reports broken Death Knight face/eye combinations that can crash the client. Donor DK-only
rows were excluded; all existing DK rows remain. Donor NPC tables, custom race IDs, and Goblin data with
no added ordinary choices were excluded.

Resolved 145 missing texture references: 143 referenced overlays were replaced with a verified fully
transparent overlay of the same component, and two missing Undead textures were recovered by exact
filename from the existing Ascension extraction. Their hashes are recorded in `merge-report.json`.
Facial-only donor colors without ordinary hairstyle textures are excluded from the new palette.
